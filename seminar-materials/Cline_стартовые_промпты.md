# Доработка платформы AIOS с помощью Cline: стартовые промпты

Памятка для команд стартапов — участников сессии. Cline — ИИ-помощник в VS Code. Вы пишете ему
задачу обычными словами, он сам меняет файлы платформы и показывает каждое
действие. Правила работы с этой платформой Cline берёт из файла `.clinerules`
в папке платформы. Его не нужно открывать или менять.

Задачи ниже составлены под эту версию платформы и правила `.clinerules`:
каждая укладывается в один-два промпта и проверяется в браузере.

## Перед началом (5 минут)

1. Запустите платформу двойным щелчком: `start_windows.bat` (Windows) или
   `start_mac.command` (Mac). Не закрывайте чёрное окно.
2. Откройте в VS Code папку платформы: «Файл → Открыть папку».
3. Откройте панель Cline (значок слева) и проверьте, что модель подключена:
   ключ выдают организаторы.
4. Сохраните исходную версию — первый промпт:

```
Сохрани текущую версию платформы, чтобы я мог к ней вернуться: если папка
ещё не под git — инициализируй git и сделай коммит «исходная версия».
```

## Как работать

- **Одна задача — один промпт.** Дождитесь, пока Cline закончит, и проверьте
  результат в браузере. Только потом переходите к следующей задаче.
- **Сначала план.** Cline покажет план — прочитайте его. Если что-то не то,
  поправьте словами: «не надо трогать меню», «цифры возьми такие».
- **Разрешения.** Cline спрашивает разрешение на правку файлов и команды.
  Нажимайте «Approve», если действие соответствует плану.
- **Проверка.** Обновите страницу с полной перезагрузкой: Ctrl+F5 (на Mac —
  Cmd+Shift+R). Если Cline сказал, что нужен перезапуск, закройте чёрное окно
  и снова запустите платформу двойным щелчком.
- **Квадратные скобки** в промптах — места, куда подставить своё. Скобки
  уберите.

## Разминка. Знакомство с платформой (5 минут)

Ничего не меняет — помогает понять, где что лежит.

```
Объясни простыми словами, из каких разделов состоит платформа AIOS ·
Техностартап и в каких файлах лежат данные рабочего стола стартапа.
Ничего не меняй.
```

## 1. Данные своего стартапа на рабочем столе (10 минут)

**Что получится:** дашборд покажет ваш стартап, ваши гипотезы и вашу воронку.

```
Замени в данных рабочего стола стартапа название на «[Название стартапа]»,
описание — на «[одна фраза: продукт для кого и какую проблему решает]».
Замени гипотезы на наши:
1) [тип: проблема / сегмент / ценность / цена / канал / рост] — [формулировка],
   критерий: [измеримый порог], статус: [бэклог / проверяется / подтверждена /
   опровергнута];
2) ...;
3) ...
Воронку замени на наши цифры: контакты [число], интервью [число], проблема
подтверждена [число], демо [число], LOI [число], платящие клиенты [число].
Остальные демо-данные оставь.
```

**Проверка:** «Рабочий стол стартапа» → Ctrl+F5 → в заголовке ваш стартап, на
доске гипотез и в воронке — ваши данные.

**Если не видно:** нажмите на дашборде «Вернуть демо-данные». Раньше
загруженный файл перекрывает данные из папки платформы.

## 2. Новая плитка показателя (10 минут)

**Что получится:** ещё одна плитка в ряду KPI над дашбордом. Значение
считается по уже имеющимся данным.

```
Добавь на рабочий стол стартапа плитку KPI «Сквозная конверсия воронки»:
доля платящих клиентов от контактов в процентах с одним знаком после
запятой. Подсвечивай плитку красным, если меньше 1 %. Все плитки должны
остаться в одном ряду.
```

**Проверка:** Ctrl+F5 → в ряду плиток появилась «Сквозная конверсия воронки»,
например «0,7 %».

**Ещё идеи:** «Доля опровергнутых гипотез, %», «Месяц, когда кончатся деньги»,
«Выручка за последний фактический месяц».

## 3. Новый виджет с графиком (20 минут)

**Что получится:** новый блок на дашборде со столбчатой диаграммой и
подсказками при наведении.

```
Добавь на рабочий стол стартапа виджет «Интервью с клиентами по неделям»:
столбчатая диаграмма за последние 8 недель, над каждым столбцом число
интервью, при наведении — сколько из них подтвердили проблему. Данные
добавь новым блоком в данные дашборда, заполни правдоподобными демо-цифрами
и подпиши, что это демо-данные. Виджет — на всю ширину, сразу после воронки.
```

**Проверка:** Ctrl+F5 → под воронкой новый виджет с восемью столбцами.
Наведите мышь на столбец — появится подсказка.

**Ещё идеи:** «Пилоты: клиент, срок, метрика пилота, статус», «Заявки на
гранты: подано / на рассмотрении / поддержано», «Трафик лендинга и заявки».

## 4. Новый раздел в меню (25 минут)

**Что получится:** новая страница с таблицей и фильтром и пункт в левом меню
на всех страницах.

```
Сделай новый раздел «Клиенты и интервью» в группе «Каталоги» левого меню:
таблица респондентов (компания или тип клиента, роль, сегмент, дата
интервью, главная проблема, цена проблемы, сигнал спроса: нет / слабый /
сильный, следующий шаг) и кнопки-фильтры по сегменту над таблицей. Данные —
отдельным файлом, заполни 6 демо-записями без ФИО и подпиши, что данные
демонстрационные.
```

**Проверка:** Ctrl+F5 → в меню слева появился пункт «Клиенты и интервью» на
любой странице. Раздел открывается, фильтр по сегменту работает.

**Дальше:** «В разделе „Клиенты и интервью“ добавь над таблицей счётчики:
сколько интервью в каждом сегменте и доля сильных сигналов».

**Ещё идеи:** «Конкуренты — подробная карта», «Календарь грантов и
акселераторов», «База контактов для пилотов».

## 5. Новое поле в карточке проекта (15 минут)

**Что получится:** в карточке проекта и в форме её правки появится новое
поле. Его начнёт спрашивать и агент онбординга.

```
Добавь в карточку проекта поле «Главный конкурент» (до 300 символов):
показывай его в карточке и в форме редактирования. Пусть агент онбординга
спрашивает о нём на шаге про клиента и проблему для стартапов.
```

**Проверка:** **нужен перезапуск платформы** — закройте чёрное окно и
запустите снова. Затем «Проекты» → откройте проект → «Редактировать» →
заполните «Главный конкурент» → «Сохранить» → поле видно в карточке.
Проектов пока нет? Сначала пройдите онбординг: «Кабинет» → «Создать новый
проект».

**Ещё идеи:** «Ссылка на лендинг», «Статус лицензии от вуза».

## 6. Свой агент (15 минут)

**Что получится:** новый агент в каталоге «Агенты». Его можно запустить
в рабочем чате.

```
Создай агента «Аналитик отраслевых закупок» в разделе агентов команды: он
уточняет у пользователя продукт и сегмент, подсказывает, какие ключевые
слова искать в ЕИС закупок, разбирает выгрузку закупок, которую загрузит
пользователь (Excel или CSV), и выдаёт таблицу: заказчик, предмет закупки,
цена, требования, насколько закупка похожа на наш продукт. Цены и
заказчиков не выдумывает — только из загруженного файла.
```

**Проверка:** «Агенты» → раскройте «Агенты вашей команды» → карточка
«Аналитик отраслевых закупок». Запустите его в рабочем чате (нужен
подключённый LLM) и загрузите любую таблицу закупок.

**Ещё идеи:** «Секретарь трекинг-сессии», «Редактор заявки на грант»,
«Патентный разведчик по нашей технологии».

## 7. Свой пример полигона (15 минут)

**Что получится:** новый пример в «Полигонах» с вашей гипотезой и
сценариями.

```
Добавь пример полигона «Нанять второго разработчика сейчас или после
гранта». Гипотеза: даже с наймом сейчас деньги не закончатся до конца
18-го месяца хотя бы в 70 % прогонов. Базовый сценарий — найм после гранта.
Сценарий «Нанять сейчас»: постоянные расходы на 150 тыс. ₽ в месяц больше,
цикл сделки короче на месяц. Идея для ИИ-фокус-группы — короткое описание
решения. Остальные параметры возьми из примера «Runway до pre-seed раунда».
```

**Проверка:** «Полигоны» → Ctrl+F5 → новая карточка → «Запустить
симуляцию» → видно, в какой доле прогонов гипотеза подтверждается.

**Дальше:** «Подставь в полигон наши цифры: деньги [сумма], расходы
[сумма] в месяц, цена [сумма], CAC [сумма]».

## 8. Карточка в новом чате (10 минут)

**Что получится:** новая подсказка в блоке «Чем займемся сегодня» на
стартовом экране рабочего чата.

```
Добавь в «Чем займемся сегодня» в новом чате карточки «Письмо клиенту»
(приглашение на интервью), «Лендинг» (текст страницы для smoke-теста) и
«Протокол трекинга» (протокол встречи с трекером по тезисам). Иконки — в
стиле остальных карточек.
```

**Проверка:** Ctrl+F5 → «Новый чат» → среди карточек появились новые.
Нажмите карточку — в поле ввода подставится начало фразы.

## Если что-то пошло не так

**Страница пустая или кнопка не работает:**

```
После твоей правки [что не работает, на какой странице]. Вот что в консоли
браузера (F12 → вкладка Console): [вставьте красный текст или приложите
скриншот]. Найди и исправь причину.
```

**Платформа не запускается после правки:**

```
Платформа не запускается после последней правки. Вот текст из чёрного окна:
[вставьте текст или приложите скриншот]. Исправь ошибку.
```

**Cline не может починить за 2–3 попытки — откатитесь:**

```
Откати все изменения последней задачи и верни платформу к последней
сохранённой версии. Потом предложи, как сделать эту задачу меньшими шагами.
```

Ещё способ откатиться: у каждого шага в Cline есть кнопка «Restore» —
возврат к состоянию до этого шага.

**Удачная доработка — сохраните версию:**

```
Сохрани текущую версию платформы коммитом «[что сделано]».
```

## Своя задача

Когда освоитесь, формулируйте задачи сами по схеме:

> **Что** добавить или изменить → **где** (страница, раздел, виджет) →
> **какие данные** (свои или демо) → **как должно выглядеть или работать**.

Пример: «На странице „Проекты“ добавь над карточками фильтр по типу проекта:
все / стартапы / рабочие задачи».

Большую идею сначала обсудите с Cline: «Хочу [идея]. Предложи план из
небольших шагов, ничего пока не меняй».
