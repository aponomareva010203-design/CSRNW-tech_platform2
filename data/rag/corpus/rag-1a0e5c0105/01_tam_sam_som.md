# Размер рынка: TAM, SAM, SOM

> Методический конспект для команд стартапов. Основано на общепринятой практике
> венчурной индустрии; цифры в примерах — демонстрационные.

## Три уровня рынка

- **TAM (Total Addressable Market)** — весь объём рынка: все клиенты, которые в принципе
  могли бы купить решение задачи, × сколько они тратят в год.
- **SAM (Serviceable Available Market)** — часть TAM, доступная нашему продукту: подходящие
  отрасли, размер компаний, география, технические ограничения, наш канал.
- **SOM (Serviceable Obtainable Market)** — часть SAM, которую реально получить за 3–5 лет
  с нашей командой, деньгами и конкурентами.

Инвестор смотрит на все три: TAM показывает потолок, SOM — реалистичность плана. SOM,
равный 30 % SAM за 3 года у команды из трёх человек, вызывает недоверие.

## Метод «снизу вверх» (основной)

```
TAM = число потенциальных клиентов × средний годовой чек
SAM = TAM × доля, доступная продукту и каналу
SOM = SAM × достижимая доля за 3 года
```

Каждый множитель — отдельное допущение с источником. Пример (демо):

| Шаг | Значение | Источник / допущение |
|---|---|---|
| Промышленные предприятия с парком вращающегося оборудования | 6 600 | Статистика по ОКВЭД, отбор по численности — оценка команды |
| Средний годовой чек на мониторинг состояния | 900 тыс. ₽ | Интервью: бюджет ТОиР и цены альтернатив |
| TAM | ≈ 5,9 млрд ₽ в год | |
| Доля: пищевая и химическая отрасли, европейская часть РФ | 40 % | Наш канал и логистика монтажа |
| SAM | ≈ 2,4 млрд ₽ в год | |
| Достижимая доля за 3 года | 2 % | Два продавца, цикл сделки 3–6 месяцев |
| SOM | ≈ 47 млн ₽ в год | ≈ 53 клиента |

## Метод «сверху вниз» (только для сверки)

Берётся объём рынка из отраслевого отчёта и умножается на долю сегмента. Метод быстрый,
но опасный: отчёты часто считают рынок шире вашей задачи, а «1 % от большого рынка» ничего
не говорит о том, кто и почему купит. Используйте его для проверки порядка величины.

## Ценностный метод (для новых рынков)

Если рынка ещё нет, оценивайте через ценность для клиента: сколько стоит проблема
(потери, время, штрафы) × число клиентов × доля ценности, которую клиент готов отдать
поставщику (часто 10–30 %).

## Чек-лист проверки расчёта

1. Каждое число имеет источник или помечено как «оценка команды — проверить».
2. Единицы согласованы: рубли в год, а не «рубли за всё время».
3. SAM учитывает ограничения продукта (например, только беспроводные датчики, только
   предприятия с доступом к сети).
4. SOM сходится с воронкой продаж и численностью команды.
5. Проведён анализ чувствительности: что будет, если ключевое допущение ошибается вдвое.
